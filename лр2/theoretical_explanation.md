# Теоретическое пояснение к лабораторной работе № 2

## 1. Генетический алгоритм

Генетический алгоритм (ГА) — стохастический метод поиска и оптимизации, в котором множество возможных решений развивается по поколениям. Каждое решение представляется хромосомой, а группа решений образует популяцию. Качество решения оценивается целевой функцией или функцией приспособленности.

Типичный цикл ГА включает:

1. формирование начальной популяции;
2. расчет значений целевой функции;
3. отбор родителей;
4. скрещивание выбранных родителей;
5. мутацию потомков;
6. перенос элитных решений;
7. проверку критерия остановки.

Для задачи минимизации удобно непосредственно сравнивать значения целевой функции: меньшая стоимость означает более приспособленную особь. Это исключает необходимость преобразовывать значения в отрицательную или положительную шкалу приспособленности.

## 2. Вещественное представление хромосомы

В данной работе хромосома имеет вид вещественного вектора:

```text
x = (x1, x2, ..., xn).
```

Каждый ген соответствует одной переменной задачи. Такое представление не требует двоичного кодирования и последующего декодирования, поэтому точность решения определяется типом чисел и параметрами операторов. Оно особенно удобно для непрерывных оптимизационных задач.

## 3. Функция варианта 4

В методичке вариант 4 назван перемещенным осевым гиперэллипсоидом и для него указаны минимум `f(x)=0` и точка `x_i=5*i`. Чтобы название функции и указанный минимум были одновременно выполнены, в программе используется математически согласованная форма:

```text
f(x) = sum(5*i * (x_i - 5*i)^2),  i = 1..n.
```

Аналитическое решение:

```text
x* = (5, 10, ..., 5*n),
f(x*) = 0.
```

Функция выпуклая и имеет единственный глобальный минимум. Коэффициенты `5*i` делают поверхность вытянутой вдоль координатных направлений, а слагаемые `(x_i - 5*i)` перемещают центр минимума от начала координат.

## 4. Операторы алгоритма

### 4.1 Турнирный отбор

Из популяции случайно выбираются несколько кандидатов. Родителем становится кандидат с наименьшим значением целевой функции. Повторение процедуры позволяет выбирать одного индивидуума несколько раз и одновременно сохраняет случайную составляющую поиска.

### 4.2 BLX-alpha кроссовер

Для двух родителей `a` и `b` для каждого гена вычисляется интервал между минимальным и максимальным значениями родителей. Затем этот интервал расширяется на `alpha` его длины, и ген потомка выбирается равномерно:

```text
low  = min(a, b) - alpha * |a - b|
high = max(a, b) + alpha * |a - b|
h    ~ Uniform(low, high).
```

В работе используется `alpha=0.5`. После кроссовера координаты ограничиваются допустимым диапазоном поиска.

### 4.3 Мутация

Для каждого гена с вероятностью `p_m` добавляется случайное нормальное возмущение. Среднее возмущение равно нулю, поэтому мутация не задает направленное смещение. После изменения ген снова ограничивается границами поиска.

### 4.4 Элитизм

Несколько лучших особей текущего поколения без изменений переносятся в следующее. Элитизм предотвращает потерю уже найденного решения из-за случайного скрещивания или мутации.

### 4.5 Критерий остановки

Выполнение завершается при достижении максимального числа поколений или после `patience` поколений без улучшения лучшего значения. Второе условие сокращает вычисления, когда популяция уже стабилизировалась.

## 5. Критерии эффективности

В эксперименте измеряются:

- время работы;
- число поколений до остановки;
- значение целевой функции в найденной точке;
- евклидово расстояние найденной точки до аналитического оптимума.

Поскольку алгоритм стохастический, один запуск не является достаточным основанием для вывода. Для каждого набора параметров выполняются повторные запуски с различными фиксированными seed, а в таблицах используется медиана результатов.

## 6. Ограничения метода

ГА не гарантирует нахождение глобального минимума за конечное число поколений. Результат зависит от размера популяции, вероятностей скрещивания и мутации, диапазона поиска и критерия остановки. Слишком маленькая популяция может привести к потере разнообразия, а слишком большая увеличивает время одной итерации. Нулевая вероятность мутации повышает риск преждевременной сходимости, а чрезмерная вероятность мешает локальной настройке.
