# Лабораторная работа 2 — вариант 4

Вариант 4 — перемещенный осевой гиперэллипсоид. Реализация использует вещественные хромосомы, турнирный отбор, BLX-alpha кроссовер, мутацию, элитизм и остановку по стабильности лучшего результата.

## Запуск

Из корня репозитория:

```text
python лр2/run_experiments.py
python -m pytest -q
```

Эксперименты сохраняются в `results/`. Основные результаты находятся в `results/results_summary.json`, таблицы — в CSV, графики — в PNG.

## Файлы

- `variant4_ga.py` — реализация алгоритма и независимый запуск SciPy.
- `run_experiments.py` — базовые запуски и параметрическое исследование.
- `tests/test_variant4_ga.py` — автоматические тесты.
- `theoretical_explanation.md` — теоретическое пояснение.
- `report.docx` — редактируемый отчет по форме ГУАП.
- `report.pdf` — PDF-копия отчета.

В отчете функция записана как `sum(5*i*(x_i - 5*i)^2)`, поскольку именно эта форма согласует название «перемещенный» и указанную в методичке точку минимума `x_i=5*i`.
