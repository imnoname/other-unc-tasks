# Лабораторная работа 1 — вариант 20

В проекте две самостоятельные программы по заданиям из методички.

## 1. Вариационная задача

Файл `variant20_variational.py` использует SymPy и выполняет символьные
вычисления по образцу из методички:

- формирует уравнение Эйлера–Лагранжа;
- находит экстремаль с заданными граничными условиями;
- вычисляет значение функционала на экстремали.

Запуск:

```text
python variant20_variational.py
```

## 2. Раскрой фанеры

Файл `variant20_cutting.py` задаёт целочисленную модель:

```text
min 12*x1 + 16*x2

2*x1 + 6*x2 >= 24
5*x1 + 4*x2 >= 31
2*x1 + 3*x2 >= 18
x1, x2 >= 0, целые
```

Программа перебирает все целочисленные допустимые планы в точной конечной
области и выбирает план с минимальными отходами.

Запуск:

```text
python variant20_cutting.py
```

Установка зависимости для первой программы:

```text
python -m pip install -r requirements.txt
```

Проверка:

```text
python -m pytest -q
```
