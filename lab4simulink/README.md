# Лабораторная работа 4 — вариант 20

[Отчёт](Отчет.md) · [Описание четырёх схем](Описание%20схем.md) · [Математическая теория](Математическая%20теория.md)

Модели `.slx` предназначены для MATLAB R2023a и Simulink. Непрерывная и дискретная модели каждого задания имеют суффиксы `d0` и `d1` соответственно. Откройте модель и нажмите Run. Исходные параметры и начальные условия заданы внутри модели; экспериментальный скрипт временно изменяет их без сохранения в `.slx`.

Для воспроизведения графиков и таблицы откройте эту папку как Current Folder и выполните `run_experiments`. Результаты сохранятся в `figures/` и `results.csv`. Скрипт `verify_models` проверяет конечные значения непрерывных и дискретных моделей по точным формулам и явной схеме Эйлера. Внимание: сценарии перезаписывают файлы результатов в этой папке.
