# Лабораторная работа 5 - вариант 4

Оптимизация многомерной функции эволюционной стратегией. Использована напечатанная в методичке функция варианта 4 `f(x) = sum(5*i*x_i^2)`, `i=1..n`, на области `[-5.12, 5.12]`.

## Запуск

Из корня репозитория:

```text
python lr5/run_experiments.py
python -m pytest -q lr5/tests
python lr5/build_report.py
```

Сценарий выполняет базовые запуски для `n=2` и `n=3`, исследует размер популяции и вероятность мутации, сохраняет JSON/CSV и изображения. Отчет собирается в `report.docx`, PDF-версия - в `report.pdf`.

## Состав

- `evolution_strategy.py` - вещественная `(mu+lambda)`-ЭС с самоадаптацией `sigma`.
- `run_experiments.py` - базовые серии, сравнение `n=2` и `n=3`, исследование параметров и графики.
- `theoretical_explanation.md` - теория ЭС, противоречие в формулировке варианта и контрольный вопрос 4.
- `build_report.py` - сборка отчета по форме ГУАП.
- `tests/test_es.py` - автоматические проверки.
