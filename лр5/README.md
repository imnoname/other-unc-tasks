# Лабораторная работа № 5 — вариант 20

Отчёт по синтезу конечного автомата для регулярного выражения `a⟨b⟩⟨(c|d)⟩⟨e⟩` и программа на Python.

## Запуск

Из корня репозитория:

```powershell
python лр5/finite_automaton_synth.py лр5/data/variant20.regex -o лр5/output/variant20_automaton.txt
```

Программа разбирает регулярное выражение, синтезирует детерминированный автомат и записывает его автоматную матрицу в UTF-8-файл. Допускаются буквенные символы, конкатенация, альтернатива `|`, круглые скобки и итерационные скобки `⟨…⟩`.

## Файлы

- `Отчет_ЛР5_вариант20.docx` — отчет с расчетом, автоматом в трех формах, контрольными вопросами и листингом программы.
- `finite_automaton_synth.py` — синтезатор и CLI.
- `data/variant20.regex` — входное регулярное выражение.
- `output/variant20_automaton.txt` — результат работы программы.
- `Граф_КНА_вариант20.png` — граф автомата.
- `build_report.py` — исходник сборки отчета.
- `test_finite_automaton_synth.py` — проверки синтеза и допустимости слов.
