# Лабораторная работа 3 - вариант 4

Тема: решение задач комбинаторной оптимизации генетическим алгоритмом на примере задачи укладки рюкзака.

Вариант 4 использует двоичное кодирование, тест P04 для простой задачи, набор 7 для повышенной задачи и контрольный вопрос 4.

## Запуск

Из корня репозитория:

```text
python lr3/run_experiments.py
python -m pytest -q lr3/tests
```

Эксперименты сохраняются в `results/`: JSON-сводка, CSV-таблицы и PNG-графики. Отчет собирается командой:

```text
python lr3/build_report.py
```

## Файлы

- `data.py` - данные P04 и набора 7.
- `knapsack_ga.py` - двоичный генетический алгоритм и точный динамический эталон.
- `run_experiments.py` - базовые запуски и исследование параметров.
- `tests/test_knapsack_ga.py` - автоматические тесты.
- `theoretical_explanation.md` - теоретическое пояснение и ответ на контрольный вопрос.
- `build_report.py` - сборка редактируемого отчета по официальной форме ГУАП.
- `report.docx` и `report.pdf` - итоговые форматы отчета.
