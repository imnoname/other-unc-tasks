# Лабораторная работа 3 МНК вариант 20

В работе исследуется ряд о числе женщин на 1000 мужчин в возрасте 20–24 лет в Российской Федерации за 2012–2019 годы.

## Содержимое

- `program.py` — программа ручного и библиотечного МНК;
- `test_program.py` — автоматические проверки расчётов;
- `report.docx` — оформленный отчёт;
- `plot.png` — график исходного ряда и моделей;
- `results.txt` — текстовые результаты;
- `results.csv` — таблица результатов.

## Запуск

Из каталога `lr3/mnk_variant20`:

```bash
python program.py
python -m pytest test_program.py -q
```

Используются NumPy и Matplotlib. Последняя точка 2019 года оставляется для валидации; визуально выбран полином степени `p = 3`, а лучшей из трёх итоговых моделей по скорректированному `R²` признана ручная квадратичная модель.
