# ЛР5, вариант 20 (2026)

Комплект содержит редактируемый отчёт, PDF-копию, MATLAB-сценарии, модель Simulink, графики и исходные числовые таблицы.

## Запуск

Требуется MATLAB R2023a с Simulink.

1. Откройте MATLAB и установите `lr5_2026_variant20` текущей папкой.
2. Запустите `run_part1.m` для нелинейной модели, регулятора макропеременной и дополнительных серий по точности, шагу, T и начальным условиям.
3. Запустите `build_part2_model.m` для пересборки `model/lr5_v20_part2.slx`, симуляций при K={9,90,900} и обновления графиков/CSV.
4. Откройте `model/lr5_v20_part2.slx`, чтобы просмотреть структурную схему.

## Исходные данные

Из методички: a=λ=1, ε=0.01, α=0.4, δ={0.1, 0.130881, 0.15, 0.196565}; W1=90; W2=1/(0.1s²+s+1). Во второй части изменяется K=W1 в десять раз вниз и вверх.

Методичка не задаёт стартовые условия, ρ, T и шаг интегрирования первой части. В сценарии приняты x1(0)=6, x2(0)=4, ρ=1, T=1, h=0.1, tEnd=200; эти настройки прямо обозначены в отчёте как экспериментальные допущения.

## Структура

- `Отчет_ЛР5_вариант20.docx` — редактируемый отчёт.
- `Отчет_ЛР5_вариант20.pdf` — PDF, экспортированный через Microsoft Word.
- `build_report.py` — генератор DOCX из официальной формы титульного листа и результатов.
- `run_part1.m`, `build_part2_model.m` — воспроизводимые сценарии MATLAB.
- `model/lr5_v20_part2.slx` — модель автоматического регулирования.
- `figures/` — фазовые портреты, временные зависимости, схема Simulink и графики переходных процессов.
- `results/` — CSV-таблицы, исходные временные ряды в MAT-файлах и настройки блоков.

## Численные оговорки

Режим 15 значащих цифр использует обычную двойную точность MATLAB. Режим 2 значащих цифр имитируется программным округлением промежуточных значений интегратора; это не аппаратная арифметика с двухзначной мантиссой. Очень малые популяции порядка 10^-80 интерпретируются как численный ноль. Показатели части 2 рассчитаны на интервале 0–2 с; окончательные значения и статические ошибки дополнительно сверены с аналитическими выражениями замкнутого контура.
