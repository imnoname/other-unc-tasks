# Лабораторная работа 7 — вариант 4

Реализация и отчёт по лабораторной работе о применении метода роя частиц (PSO) к оптимизации многомерной функции.

## Состав

- `pso.py` — алгоритм PSO с глобальным лучшим решением, ограничением скорости и отражением от границ.
- `run_experiments.py` — демонстрационный запуск и серии экспериментов; сохраняет CSV/JSON и графики в `results/`.
- `build_report.py` — формирует DOCX по титульному шаблону ГУАП и обновляет отчёт.
- `report.docx`, `report.pdf` — итоговый отчёт.
- `results/` — использованные численные данные и иллюстрации.

## Запуск

Нужен Python 3 и пакет Pillow. В каталоге `lr7` выполните:

```powershell
python run_experiments.py
python build_report.py
```

`run_experiments.py --verbose` печатает подробности демонстрационного поиска. Для экспорта PDF скрипт отчёта использует Microsoft Word, установленный в Windows.

## Принятые допущения варианта 4

В методичке текстовое описание смещённого эллипсоида расходится с напечатанной формулой. Использована согласованная со смещением постановка `f(x)=Σ 5i·(xᵢ−5i)²`, минимум которой равен нулю в точке `(5, 10, …, 5n)`. Для экспериментов задан диапазон координат `[-55, 55]`, который включает целевые координаты исследованных размерностей. Подробное обоснование и результаты приведены в отчёте.
