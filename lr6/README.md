# Лабораторная работа 6 — вариант 4

Локальная работа с алгоритмом муравьиной колонии на данных Bayg29 (29 городов из методических указаний).

## Реализованные части

1. Кратчайший гамильтонов путь: открытый маршрут, ребро возврата не добавляется.
2. Задача коммивояжера: замкнутый цикл с возвратом в исходный город.

Методичка приводит эталонный цикл Bayg29. Для открытого пути тот же маршрут после удаления последней дуги дает лишь допустимую верхнюю оценку, а не доказанный оптимум открытого пути.

## Запуск

```text
python lr6/run_experiments.py
python lr6/run_experiments.py --verbose
```

Краткий режим показывает постановку, настройки, найденные маршруты, длины, время, сравнение с эталонным туром, сводку параметрического исследования и пути к файлам. Подробный режим печатает результат каждой итерации.

Результаты записываются в `results/`: JSON/CSV, изображения пути и цикла, график сходимости.
