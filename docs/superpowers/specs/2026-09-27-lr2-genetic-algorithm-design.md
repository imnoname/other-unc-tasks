# Лабораторная работа 2 по эволюционным методам

## Цель

Подготовить воспроизводимое выполнение лабораторной работы № 2 по оптимизации многомерной функции генетическим алгоритмом для варианта 4, оформить результаты в отчете по требованиям ГУАП и сохранить материалы в папке `лр2`.

## Исходные требования

- Вариант 4: перемещенный осевой гиперэллипсоид.
- Целевая функция:
  \[
  f(x)=\sum_{i=1}^{n}5i\,x_i^2,
  \qquad x_i=5i,
  \qquad f_{min}=0.
  \]
- Нужны результаты для `n=2` и `n=3`, визуализация для `n=2`, анализ параметров популяции, кроссовера и мутации, а также сравнение с независимой реализацией.
- Реализация выполняется на Python с вещественным представлением хромосомы.

## Архитектура результата

1. `variant4_ga.py` — чистые функции целевой задачи, реализация вещественного ГА, запуска экспериментов и сериализации результатов.
2. `run_experiments.py` — воспроизводимый запуск всех серий измерений и построение графиков.
3. `tests/test_variant4_ga.py` — тесты целевой функции, границ, операторов и сходимости на фиксированном seed.
4. `results/` — таблицы CSV/JSON и PNG-графики.
5. `report.docx` — итоговый отчет на основе официального бланка ГУАП.
6. `theoretical_explanation.md` — отдельное теоретическое пояснение с формулами, описанием операторов и интерпретацией результатов.

## Алгоритмические решения

- Хромосома — вектор вещественных генов.
- Диапазоны поиска выбираются симметрично вокруг известного смещения задачи, чтобы алгоритм не получал оптимум напрямую: для каждой координаты используются общие учебные границы, содержащие ожидаемый минимум.
- Для задачи минимизации приспособленность вычисляется через ранжирование/инверсию значения целевой функции, без отрицательных или нулевых вероятностей отбора.
- Отбор — турнирный; сохранение лучшей особи — элитизм.
- Скрещивание — BLX-alpha с ограничением результата границами поиска.
- Мутация — случайная вещественная мутация отдельных генов с ограничением границами.
- Остановка — максимальное число поколений либо заданное число поколений без улучшения.
- Все эксперименты используют фиксированные seed и одинаковые критерии остановки для сопоставимости.

## Состав отчета

Титульный лист, содержание, задание с вариантом 4, краткие теоретические сведения, постановка задачи, описание алгоритма, листинг, графическая визуализация, экспериментальные таблицы, сравнение реализаций, результаты для `n=2` и `n=3`, выводы, список источников и приложения.

## Оформление

Используется официальный бланк отчета о лабораторной работе ГУАП и опубликованные ГУАП требования к учебным работам: Times New Roman 14 пт для основного текста, полуторный интервал, абзац 1,25 см, поля 20/20/30/15 мм, сквозная нумерация страниц с номером снизу по центру без номера на титульном листе, структурные элементы с новой страницы, ссылки на рисунки и таблицы, содержание и библиографическое описание источников.
