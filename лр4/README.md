# Лабораторная работа № 4 — вариант 20

Отчёт и исходные файлы автомата Мили для регулярного выражения `a⟨b⟩⟨(c|d)⟩⟨e⟩`.

## Запуск программы

```powershell
python finite_automaton.py acdeee
```

Программа проверяет слово по таблицам переходов и выходов, ориентированному графу и матрице переходов-выходов, показывая траектории, выходы и результат.

Пустые повторы разрешены, поэтому слово `a` принимается.

## Файлы

- `Отчет_ЛР4_вариант20.docx` — оформленный отчёт.
- `Диаграмма_КНА_вариант20.png` — граф автомата.
- `finite_automaton.py` — исполняемая программа.
- `test_finite_automaton.py` — тесты программы.
- `build_report.py` — исходник сборки отчёта; использует `lab_title.docx`.
- `DESIGN.md` — описание принятого решения.
