# Automata Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement task-by-task.

**Goal:** Учебная программа с GUI и воспроизводимый реферат о синтезе и минимизации КА.

**Architecture:** Чистое ядро, файловые операции и независимый оконный интерфейс. Отдельные тесты и построитель документа.

**Tech Stack:** Python, unittest, Tkinter, python-docx; bundled runtime для документа.

**Spec:** design.md

## Global Constraints
- Метод мест ЛР5 и минимизация Мили из конспекта.
- Сохранить выходы, в распознавателе также конечность и пустое слово.
- GUI и документация на русском; запуск без pip.
- Существующие файлы пользователя не изменять.

## Review Focus
- Смешанные/вложенные скобки и одинаковые буквы в разных позициях.
- Пустое слово и продолжение уже принятого слова.
- Эквивалентные по языку, но разные по выходам состояния Мили.
- Ошибочные типы JSON и неверный алфавит.
- Повторная сборка после ошибки не оставляет старый результат действующим.
