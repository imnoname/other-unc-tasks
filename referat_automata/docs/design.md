# Синтез и минимизация конечного автомата

Пользователь поручил самостоятельно выбрать реализацию, попросил GUI, подробный реферат ГУАП и скриншоты событий. Подтверждены Могилатов Семен Игоревич, Охтилев Михаил Юрьевич, группа 4332, кафедра 43, Теория вычислительных процессов.

Python 3.12+ и Tkinter без внешних зависимостей для запуска. Отдельная папка самостоятельного учебного проекта, существующие лабораторные не изменяются. Два режима: регулярное выражение по ЛР5; произвольный полный автомат Мили в JSON (в том числе лекционный пример). GUI показывает исходный и минимальный автоматы, графы, места и подчинение, разбиения, трассы слов. Импорт/экспорт через файлы, сообщения о результатах и ошибках, встроенная справка.

Метод мест реализуется буквально правилами ЛР5: основные индексы у начального места и после букв, подчинение как ориентированные связи, рефлексивно-транзитивное замыкание, распространение индексов, построение достижимых подмножеств. Сначала полный автомат с пустым состоянием, затем минимизация. Не копировать ошибочную таблицу подчинения и преждевременное объединение индексов из примера ЛР5. Нулевое число повторений разрешено. Поддерживается явно обозначенное расширение ε.

Минимизация Мили: удалить недостижимые состояния, сгруппировать по векторам выходов, уточнять по номерам классов переходов до устойчивости. В режиме распознавателя также сохранять метку конечности, включая ответ для пустого слова. Полный автомат нужен для однозначного отказа на продолжениях слова. Точное сравнение произведением исходного и минимального автоматов проверяет выходы и, для распознавателя, конечность. Оно не заменяет независимый тест синтеза.

Тесты: все 30 выражений ЛР5, независимый fullmatch для конечной области, генерация дополнительных вложенных выражений, лекционный пример 5→3, уточнение в несколько проходов, недостижимость, крайние случаи, неверные выражения/JSON, ошибки файлов, лимиты, повторные действия GUI, отмена диалогов, успешный экспорт. Реальные скриншоты GUI, реестр с ожидаемыми и фактическими результатами, программные проверки. Нельзя заявлять покрытие бесконечного множества входов; покрывается конечный явно описанный каталог событий.

Отчёт DOCX/PDF: теория, пошаговый синтез, лекционная минимизация, архитектура, руководство, результаты всех тестовых событий со скриншотами, ограничения, выводы, источники и полные листинги. Объём определяется содержанием, без искусственного наполнения.
