# Синтез и минимизация конечного автомата

Python 3.12+ с Tkinter. Программа и тесты используют только стандартную библиотеку.

Запуск: `python app.py` или `Run.cmd`.

Синтез следует методу мест и подчинения ЛР5. Поддерживаются конкатенация, `|`, `()`, `<>`/`⟨⟩`; `ε` - явно введённое расширение для пустого слова. Латинские буквы и цифры являются отдельными входными символами. Пробелы в РВ игнорируются.

Минимизация Мили следует лекции: недостижимость, векторы выходов, уточнение по классам целей. Для распознавателя дополнительно сохраняется конечность. После построения автоматически выполняется точная проверка произведением автоматов.

Примеры: `examples/lab5.txt`, `examples/variant20.txt`, `examples/lecture.json`.

## Повторение проверок

```text
python -m unittest discover -s tests -v
python experiments.py
python qa_visual.py --batch
```

`qa_visual.py` без аргументов показывает сценарии в настоящем окне; F9 - следующий, F8 - предыдущий. Полоса над приложением принадлежит испытательному сценарию. Диалог выбора файла/папки в сценариях подменён детерминированным путём или отменой; чтение и запись настоящие. Снимки сохраняются отдельно средствами Computer Use, сценарий их не имитирует.

`results/word_checks.csv` содержит каждый из 44 382 тестовых входов; `experiments.json` - сводку; `unittest.txt` - журнал. Продуктовая программа `app.py` не запускает тесты и не зависит от каталога tests.

## Ограничения

РВ до300 значащих знаков, вложенность40; по умолчанию256 состояний, разрешён предел1…512. JSON до512 состояний и62 входов. UTF-8 файл до32МБ. Слово до10000 знаков. Встроенный граф до40 состояний; экспорт SVG доступен для больших автоматов. Полные таблицы больших автоматов требуют прокрутки.

Экспорт пишет `original.json`, `minimal.json`, `protocol.txt`, `original.svg`, `minimal.svg` в выбранную папку; при повторном выборе той же папки имена используются повторно. Для независимых опытов выбирайте разные папки. При ошибке записи часть файлов могла быть уже сохранена; комплект считается готовым только после сообщения об успехе.

## Документ

Реферат построен на официальном бланке ГУАП с подтвержденными реквизитами. Перед листингами объяснены семантика, аргументы и результат каждой функции. Для всех 60 сценариев указаны вход, действие, ожидаемый вывод и фактический результат.

Для пересборки `build_report.py` нужны `python-docx`, исходные материалы из `sources`, результаты испытаний и три справочника из `docs`: `function_reference.json`, `function_reference_aux.json`, `scenario_inputs.json`. В рабочей среде используется bundled Python. `render_word.ps1` обновляет содержание и экспортирует PDF через установленный Microsoft Word. Эти зависимости относятся к подготовке отчета, а не к запуску учебной программы.

При дальнейших правках текста использовать обычную пунктуацию и короткий знак `-` вместо длинных тире. Сборщик дополнительно удаляет длинные тире из текстового содержимого DOCX; исходные фотографии и скриншоты сохраняет без ретуши.
