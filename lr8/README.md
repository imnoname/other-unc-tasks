# Лабораторная работа 8 — вариант 4

Калибровка степенной модели COCOMO генетическим алгоритмом на исторических данных проектов. Программа воспроизводимо делит 18 проектов на 13 обучающих и 5 тестовых, выполняет несколько запусков вещественного ГА, сравнивает результат с лог-линейной регрессией и сохраняет графики, CSV и JSON.

## Состав каталога

- `cocomo_ga.py` — вещественный генетический алгоритм для поиска коэффициентов `a` и `b`.
- `run_lab.py` — диалоговое меню и сценарий экспериментов.
- `data/projects_18.csv` — входные данные, перенесённые из таблицы 8.1 методички.
- `results/` — сводка, прогнозы по проектам, параметры независимых запусков и графики.
- `report.docx`, `report.pdf` — оформленный отчёт.
- `theoretical_explanation.md` — краткое пояснение метода и допущений.

## Запуск

Требуется Python 3.10+, Pillow и python-docx для пересборки отчёта.

```powershell
python run_lab.py
python run_lab.py --run --runs 8 --verbose
python -m unittest discover -s tests -v
python build_report.py
powershell -ExecutionPolicy Bypass -File .\export_pdf.ps1
```

Для экспорта PDF нужен Microsoft Word для Windows. Скрипт обновляет содержание и поля перед сохранением PDF.

## Выбранный вариант и допущения

Вариант 4 использует вещественную пару `(a,b)`, метрику ED, арифметическое скрещивание и вещественную мутацию, рулеточный отбор. Параметры GA: популяция 120, 600 поколений, `Pc=0.90`, `Pm=0.15`, 8 запусков. Диапазоны параметров заданы экспериментально: `a ∈ [0.05, 20]`, `b ∈ [0.1, 2.5]`.

Проект №4 в источнике имеет значение `909.8` человеко-месяца. Оно оставлено без изменений и находится в тестовой выборке фиксированного разбиения `seed=3`; отчёт также показывает тестовую ошибку без этой строки, чтобы отдельно показать её влияние.
