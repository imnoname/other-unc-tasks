# Лабораторная работа 2 по теории вычислительных процессов

Вариант 20: вычисление функции `f(x, y) = (x + 1)(y + 1)` на одноленточной машине Тьюринга.

Аргументы задаются в унарной системе счисления и разделяются символом `*`. Входная лента содержит также правый служебный разделитель `=`: например, `11*11=` соответствует `x = 2`, `y = 2`. После остановки машины на ленте остаётся `=111111111`, то есть результат `9` в унарной системе счисления.

## Запуск

```text
python tm_emulator.py --program data/variant20.tm --alphabet data/alphabet.txt --tape data/tape_2x2.txt --output output/variant20_trace.txt
```

Эмулятор считывает программу, алфавит и входную ленту из отдельных файлов, выполняет машину пошагово и сохраняет в выходной файл состояние ленты, положение головки, выполненную команду и итоговый результат.

## Проверка

```text
python -m pytest -q
```

Дополнительно проверены все 25 пар `x, y` в диапазоне от 0 до 4. Для каждой пары результат совпал с `(x + 1)(y + 1)`.
