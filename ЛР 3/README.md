# Лабораторная работа 3 по теории вычислительных процессов

Вариант 20: вычисление функции `f(x, y) = (x + 1)*(y + 1)` на канонической системе Поста.

## Источник задания

Полное задание находится в `assets/tvp3.pdf`. Вариант 20 выбран coordinator-ом и зафиксирован в `data/student_sheet.json`; общий список вариантов из методички не изменяется.

## Требования к реализации

Нужно реализовать на Python 3 эмулятор канонической системы Поста, который:

- считывает все компоненты системы из одного файла: `A`, `X`, `A1`, `R`;
- выполняет пошаговый вывод слов с применением продукций;
- сохраняет для каждого шага исходную строку, применяемое правило и результат применения;
- сообщает об успешном завершении или об ошибке алфавита/переменных;
- использует унарное представление: `x=3` — `111`, два аргумента разделяются `/`;
- реализует вариант 20: `f(x,y)=(x+1)*(y+1)`.

## Обязательный CLI-контракт

Основной файл — `post_emulator.py`.

```text
python3 post_emulator.py \
  --system data/variant20.fs \
  --input 11/111 \
  --output output/trace_2x3.txt
```

Для входа `11/111` программа должна получить 12 единиц в унарной записи. Выходной файл должен содержать протокол с полями `Исходная строка`, `Применяемое правило`, `Результат применения правила` либо их однозначными английскими эквивалентами, а также итоговую строку.

Ошибочный символ алфавита или неизвестная переменная должны приводить к ненулевому коду завершения и диагностике, явно указывающей соответствующую причину.
