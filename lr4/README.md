# Лабораторная работа 4 - вариант 4

Генетическое программирование для символьной регрессии функции `f(x) = x^6 - 2*x^4 + x^2` на 20 точках области `[-1, 1]`.

## Запуск

Из корня репозитория:

```text
python lr4/run_experiments.py
python -m pytest -q lr4/tests
python lr4/build_report.py
```

Сценарий сохраняет в `results/` JSON-сводку, CSV с обучающими точками и параметрическим исследованием, график сходимости, сравнение функций и изображения найденных деревьев на контрольных поколениях. `report.docx` - редактируемый отчет, `report.pdf` - его PDF-версия.

## Состав

- `gp_symbolic_regression.py` - узлы программных деревьев, безопасная интерпретация, генетические операторы и цикл ГП.
- `run_experiments.py` - воспроизводимые эксперименты, графики и таблицы результатов.
- `theoretical_explanation.md` - теоретическое пояснение и ответ на контрольный вопрос 4.
- `build_report.py` - сборка отчета по официальной форме ГУАП.
- `tests/test_gp.py` - автоматические тесты базовых свойств реализации.
