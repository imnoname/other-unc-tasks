# Теоретическое пояснение к лабораторной работе № 3

## 1. Задача укладки рюкзака

В задаче 0/1-рюкзака задано `n` предметов. Для предмета `i` известны вес `w_i` и стоимость `p_i`, а вместимость рюкзака равна `C`. Нужно выбрать подмножество предметов максимальной стоимости:

`max sum(p_i x_i)` при ограничении `sum(w_i x_i) <= C`, где `x_i ∈ {0, 1}`.

Единица в двоичном векторе означает, что предмет выбран, ноль - что предмет не выбран. В варианте 4 используются тест P04 простой сложности и набор 7 повышенной сложности. Для P04: `C=50`, веса `[31, 10, 20, 19, 4, 3, 6]`, стоимости `[70, 20, 39, 37, 7, 5, 10]`. Эталонный вектор `[1, 0, 0, 1, 0, 0, 0]` имеет вес 50 и стоимость 107.

## 2. Двоичное кодирование

Хромосома генетического алгоритма имеет длину `n` и состоит из нулей и единиц. Такое представление непосредственно задает выбор предметов, но случайные операции скрещивания и мутации могут создать перегруженный рюкзак. Поэтому после генетических операторов в программе выполняется восстановление допустимости: пока общий вес больше `C`, удаляется выбранный предмет с наименьшим отношением `p_i / w_i`. После восстановления хромосома является допустимой и может участвовать в следующем поколении.

## 3. Генетический алгоритм

В начале создается случайная популяция двоичных хромосом. Для каждой особи вычисляются общий вес и стоимость. Родители выбираются турнирным отбором: из нескольких случайных кандидатов выбирается особь с максимальной стоимостью. С вероятностью `p_c` применяется двухточечный кроссовер, после чего каждый ген инвертируется с вероятностью `p_m`. Две лучшие особи переносятся в новое поколение элитизмом.

Критерием качества служит стоимость допустимого решения. В экспериментах фиксируется seed генератора случайных чисел, поэтому результаты можно воспроизвести. Для проверки точности дополнительно рассчитывается точный оптимум методом динамического программирования.

## 4. Параметры исследования

В базовой серии используются популяция 60 особей и 250 поколений для P04, а для набора 7 - популяция 100 особей и 400 поколений. Исследуется влияние трех параметров: мощности популяции, вероятности кроссовера и вероятности мутации. Для каждой настройки выполняются три запуска с разными seed. Фиксируются лучшая стоимость, вес, ошибка относительно точного оптимума, процент точности и время работы.

## 5. Контрольный вопрос № 4

Алгоритм восстановления при решении задачи укладки рюкзака нужен для преобразования недопустимой особи в допустимую, если после генетического оператора суммарный вес выбранных предметов превысил вместимость рюкзака. Сначала проверяется ограничение. Если оно нарушено, из текущего решения удаляется один из выбранных предметов по заданному правилу. Процесс повторяется до тех пор, пока суммарный вес не станет не больше вместимости.

В данной работе применяется жадное восстановление по отношению стоимости к весу: удаляется предмет с минимальным `p_i / w_i`. Такой выбор старается сохранить более выгодные предметы и одновременно уменьшить перегрузку. После завершения восстановления полученная особь остается бинарной и допустимой, поэтому ее можно использовать для вычисления приспособленности и дальнейшей эволюции.
